# technical_traning

職業訓練の企業実習で取り組んだ課題や、課題に関連する資料を保存しているリポジトリです。実習で作成したファイルのほか、課題としてあらかじめ用意されていたファイルも含まれています。

## リポジトリの構成

- `課題（Aチーム）/` — Aチームの課題関連ファイル。顧客管理システムの課題プロジェクト、テスト仕様書、テスト用CSVなどを格納しています。
- `仕様書/` — 顧客管理システムの要件定義書・基本設計書・詳細設計書などの資料です。ER図の自動生成手順も含みます。
- `環境設定/` — 開発環境やデータベースの設定手順、SQLファイル、サンプルデータなどを格納しています。

## 使用技術

リポジトリの主な言語は Java と JavaScript です。データベース関連の資料・SQLも含まれています。

## 利用について

まず `環境設定/` の手順書を確認し、課題に取り組む際は `仕様書/` と `課題（Aチーム）/` の資料を参照してください。プロジェクト内には課題用のひな形や事前配布ファイルも含まれるため、作成した成果物と区別して確認してください。

## 備考

このリポジトリは職業訓練の企業実習で作成・使用した課題資料の記録を目的としています。各ファイルの内容や実行方法は、それぞれの仕様書・環境設定手順を参照してください。
